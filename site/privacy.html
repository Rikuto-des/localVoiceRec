プライバシーポリシー

最終更新日: 2026 年 5 月 27 日

本ポリシーは、Rikuto Yasuda（以下「開発者」）が提供する macOS アプリケーション localVoiceRec（以下「本アプリ」）における、利用者の情報の取扱いを定めるものです。

1. 基本方針

本アプリは、利用者のあらゆるデータを一切収集・記録・送信しません。 録音音声、文字起こし結果、要約、メタデータを含むすべてのデータは、利用者の端末内にのみ保存され、 開発者および第三者は一切アクセスできません。

2. 通信を行わない技術的保証

本アプリは macOS の App Sandbox を有効化し、ネットワーク通信用の entitlement （com.apple.security.network.client および com.apple.security.network.server）を 意図的に付与していません。これにより、オペレーティングシステムが本アプリによるネットワーク接続を 技術的に拒否します。

この事実は、配布されている .app に対して以下のコマンドを実行することで誰でも検証できます。 

codesign --display --entitlements - /Applications/localVoiceRec.app

3. 録音データの保存場所

録音音声・文字起こし・要約は、本アプリの Sandbox 内 （~/Library/Containers/com.example.localVoiceRec/Data/ 配下）にのみ保存されます。 他のアプリや外部からはアクセスできません。利用者はアプリ UI から個別または一括で削除でき、 削除時にファイル実体も同時に消去されます。

4. 端末の権限

本アプリは以下の macOS 権限を利用します。いずれもオンデバイス処理のみのために使用します。

  • マイク: 自分側の音声収録のため
  • システム音声（Core Audio Tap）: 会議相手側の音声収録のため
  • ファイル保存（ユーザーが NSSavePanel で選択した場所のみ）: 議事録のエクスポート用

これらは macOS の権限ダイアログを通じて利用者の明示的な許可を得たうえでのみ機能します。

5. 第三者サービス・解析ツール

本アプリには、解析ツール（Google Analytics、Firebase Analytics 等）、クラッシュレポーター、 広告 SDK、第三者の SaaS 連携は一切組み込まれていません。

6. 文字起こしと要約の処理

文字起こしは Apple の Speech フレームワーク（SpeechAnalyzer）を用いて 端末内で実行されます。要約は Apple Intelligence のオンデバイスモデル （FoundationModels フレームワーク）を用いて端末内で実行されます。 Apple の Private Cloud Compute は本アプリでは使用しません （ネットワーク entitlement がないため、技術的に経路が存在しません）。

7. 子供のプライバシー

本アプリは特定の年齢層を対象としていません。利用者の年齢に関わらずデータを収集しないため、 子供のプライバシーに関する追加の取扱いも発生しません。

8. 配布サイトについて

本ポリシーが掲載されている配布サイト（localvoicerec.pages.dev）は Cloudflare Pages 上でホストされています。サイト閲覧時のアクセスログ等は Cloudflare の標準的なログとして同社のプライバシーポリシーに従って取り扱われます。 開発者は閲覧者の個別アクセスログを取得・保管していません。

9. ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更を行う場合は、本ページの「最終更新日」を 更新し、必要に応じて GitHub リポジトリのリリースノートで告知します。

10. お問い合わせ

本ポリシーに関するお問い合わせは GitHub Issues よりお願いいたします。
